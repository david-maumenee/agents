2. C'est quoi un Agent ?

Un agent n'est pas juste un LLM (Large Language Model). C'est un système composite. Si le LLM est le cerveau, l'Agent est le corps entier capable d'agir sur le monde numérique.

  • 🧠
    LLM (Le Cerveau) Raisonnement, planification et compréhension du langage (ex: GPT-4, Claude).
  • 🛠️
    Tools (Les Mains) Capacité à exécuter du code, appeler des APIs, chercher sur le web.
  • 📋
    Context (La Mémoire) Instructions système, historique de conversation et mémoire à long terme.

3. La Guerre des Frameworks

Pour construire ces agents, plusieurs écoles s'affrontent. Le choix dépend de la complexité du besoin et du niveau de contrôle souhaité.

OpenAI Agent SDK

Simple, natif, idéal pour démarrer rapidement.

CrewAI

Basé sur des "rôles". Orchestration d'équipe multi-agents.

LangGraph

Contrôle par graphes (State Machine). Pour les flux complexes et déterministes.

4. MCP : Le Standard de Demain ?

Le Model Context Protocol (MCP) vise à standardiser comment les agents se connectent aux données. Fini les intégrations sur-mesure pour chaque outil.

💻

MCP Host

L'Application

Claude Desktop, IDE, Terminal

🔄

MCP Client

Le Connecteur

Gère la découverte et la sécurité

🗄️

MCP Server

La Source

Google Drive, Postgres, Slack, Github

L'agent ne code plus l'intégration, il "demande" simplement les capacités au serveur via le protocole.
